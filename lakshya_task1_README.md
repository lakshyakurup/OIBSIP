# Level 1 — Task 1: SaaS Landing Page (NexusCloud)

Oasis Infobyte Internship Program (OIBSIP) — Web Development Track  
**Intern:** Lakshya Kurup

## 📌 Overview
A modern, responsive SaaS landing page built for **NexusCloud**, featuring clean typography, high-converting call-to-action buttons, and an intuitive layout.

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS v4
- **Language:** TypeScript / React

## 🚀 Getting Started & Setup
To run this project locally:

```bash
cd lakshya_task1
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
