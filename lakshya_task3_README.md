# Level 1 — Task 3: Interactive Temperature Converter

Oasis Infobyte Internship Program (OIBSIP) — Web Development Track  
**Intern:** Lakshya Kurup

## 📌 Overview
An interactive client-side web utility tool that performs real-time temperature conversion across Celsius, Fahrenheit, and Kelvin with absolute zero validation safeguards.

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS v4
- **Language:** TypeScript / React

## 🚀 Getting Started & Setup
To run this project locally:

```bash
cd lakshya_task3
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
